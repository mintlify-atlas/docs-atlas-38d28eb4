Rekono is an offensive security platform built for penetration testers and red teams who are tired of babysitting terminals. Define a target once, and Rekono runs the full reconnaissance pipeline for you — OSINT, host discovery, port scanning, service enumeration, vulnerability detection, and exploit matching — chaining each tool's output directly into the next one.

## What Rekono does for you

Every assessment follows roughly the same sequence: gather public data, discover hosts, enumerate ports and services, check for known vulnerabilities, and search for exploits. Rekono performs that entire sequence autonomously. What one tool discovers becomes the input for the next tool — ports found by Nmap are immediately scanned by the right service-specific tools, technologies detected are checked against CVE databases, and vulnerabilities are matched against public exploit databases.

<Steps>
  <Step title="Deploy">
    Start the full stack with a single Docker Compose command. PostgreSQL, Valkey, backend workers, frontend, and Nginx TLS proxy all start together.
    ```bash
    docker compose up -d --scale executions-worker=5
    ```
  </Step>
  <Step title="Create a project and target">
    Log in at `https://127.0.0.1` with `rekono:rekono`, create a project for your engagement, and add the target domain or IP you want to assess.
  </Step>
  <Step title="Launch a task">
    Select a built-in process (or build your own) and start a task against your target. Rekono schedules and chains the executions automatically.
  </Step>
  <Step title="Review findings">
    Findings land deduplicated, enriched with CVE scores and HackTricks links, and ready for triage — confirm real vulnerabilities, dismiss false positives, and generate your report.
  </Step>
</Steps>
